# Bitácora de IA — San Javier

## Alcance real de la ayuda

Codex generó la implementación inicial del programa Java, sus pantallas Swing, modelos, acceso JDBC, modo local, scripts de ejecución, pruebas y documentación. El estudiante solicitó código acorde con su nivel y una guía para aprender a defenderlo. No se afirma que ya haya comprendido, adaptado o implementado personalmente todo el código generado.

Se consultaron las columnas, restricciones y funciones del proyecto EESSSANJAVIER mediante consultas de solo lectura. Se verificó que el stock remoto ya se actualiza mediante triggers. No se modificaron tablas ni datos operativos de Supabase.

## Decisiones y comprobaciones

Se eligió Java Swing para el escritorio, JDBC para consultas SQL y una jerarquía de movimientos para aplicar herencia y polimorfismo. La demostración utiliza H2 local con datos ficticios. Las pruebas de negocio e integración aprobaron 73 comprobaciones. La verificación de la conexión real queda pendiente de introducir la contraseña de PostgreSQL en la aplicación.
